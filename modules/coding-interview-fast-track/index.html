01 · Recognition map

Починай із wording задачі

Не шукай назву алгоритму. Шукай сигнал у вимогах.

duplicate · count · lookupHashMap / Set

Треба швидко знати: “бачив уже?”, “скільки разів?”, “де лежить complement?”.

sorted · pair · matchTwo Pointers

Два впорядковані набори або один sorted array, де pointers можуть рухатись назустріч чи вперед.

contiguous · recent · last NSliding Window

Працюємо з безперервним діапазоном і оновлюємо його замість перерахунку з нуля.

repeated min/max · top KHeap

Потрібно багато разів швидко діставати найменший/найбільший елемент або тримати Top-K.

02 · Must know

Чотири патерни — і не більше

Відео нижче — Python, але зараз це плюс: дивись на mental model, не на синтаксис. Потім відтвори ідею в Swift.

1

HashMap / Set

Найвища віддача за найменший час
“Чи бачили ми це значення?” · “Скільки разів?” · “Знайди complement.”
Team-shaped use

Deduplicate event IDs, count samples, lookup metadata by ID.

Complexity anchor

Lookup / insert — expected O(1).

Practice only

Contains Duplicate → потім Two Sum. Цього достатньо для refresh.

▶ NeetCode: Contains Duplicate~5 min explanation + code
2

Two Pointers

Особливо релевантно до timestamp streams
“Input sorted.” · “Match two streams.” · “Find pair / intersection / merge.”
Team-shaped use

Match frames from camera A and B when timestamps are close.

Mental model

Pointer, який уже “відстав”, можна рухати вперед — назад повертатись не треба.

Practice only

Two Sum II — Input Array Is Sorted. Не бери зараз 10 different pointer tasks.

▶ NeetCode: Two Sum IIПодивись solution drawing, потім закодуй у Swift
3

Sliding Window

Для contiguous ranges і recent data
“Last N samples.” · “Last 1 second.” · “Best contiguous range.”
Team-shaped use

Rolling average / count за останні 100 ms або 1 second.

Mental model

Розширюй right; коли window невалідне — рухай left.

Practice only

Best Time to Buy and Sell Stock. Якщо легко — тоді Longest Substring Without Repeating Characters.

▶ NeetCode: Best Time to Buy/Sell Stock0:52 — visual explanation
4

Heap / Priority Queue

Concept only — не реалізуй binary heap з нуля
“Repeated smallest/largest.” · “Top K.” · “Merge K streams.”
Team-shaped use

Merge кількох timestamp streams або тримати K best frames.

What to know

Min-heap швидко дає smallest; insert/pop ≈ O(log n).

Practice boundary

Kth Largest Element in a Stream. Зрозумій, чому min-heap size K працює. Реалізація heap internals — later.

▶ NeetCode: Kth Largest in a StreamHeap intuition, not memorization

04 · Interview behavior

Навіть якщо pattern не впізнав

1Clarify

Input sorted? Duplicates? Finite? Can data fit in memory?

2Start simple

Опиши brute force, навіть якщо він O(n²). Це краще, ніж мовчати.

3Find repeated work

Що ми перераховуємо? Що можна запам’ятати або рухати тільки вперед?

4Say complexity

Після working solution назви time і space та один trade-off.
