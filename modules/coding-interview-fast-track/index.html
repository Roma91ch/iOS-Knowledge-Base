Task · Contains Duplicate

Знайди, чи масив містить хоча б один duplicate

Тобі дано масив цілих чисел nums. Поверни true, якщо будь-яке значення зустрічається щонайменше двічі. Якщо всі значення унікальні — поверни false.

  • Input: [Int]
  • Output: Bool
  • Не потрібно повертати саме duplicate value — лише факт його існування.
Input: [1, 2, 3, 1] Output: true Reason: value 1 appears twice. Input: [1, 2, 3, 4] Output: false
var seen: Set<Int> = []

for value in nums {
    if !seen.insert(value).inserted {
        return true
    }
}
return false

Task · Two Sum II

Знайди два числа у sorted array, що дають target

Дано масив numbers, відсортований у non-decreasing order, і число target. Знайди два різні елементи, сума яких дорівнює target.

  • Гарантується рівно одне правильне рішення.
  • Не можна використати один і той самий елемент двічі.
  • LeetCode очікує 1-based indices; на інтерв’ю уточни indexing.
Input: numbers = [2, 7, 11, 15], target = 9 Output: [1, 2] Reason: 2 + 7 = 9 Input: numbers = [2, 3, 4], target = 6 Output: [1, 3]
var left = 0
var right = numbers.count - 1

while left < right {
    let sum = numbers[left] + numbers[right]
    if sum == target { return [left + 1, right + 1] }
    if sum < target { left += 1 }
    else { right -= 1 }
}
return []

Task · Best Time to Buy and Sell Stock

Знайди максимальний profit з однієї buy і однієї sell операції

Масив prices містить ціну акції по днях. Обери один день для покупки і пізніший день для продажу. Поверни максимальний profit. Якщо profit отримати неможливо — поверни 0.

  • Sell day повинен бути після buy day.
  • Можна виконати лише одну buy і одну sell операцію.
  • Треба знайти максимум, а не самі indices.
Input: prices = [7, 1, 5, 3, 6, 4] Output: 5 Reason: buy at 1, sell at 6 → profit = 5 Input: prices = [7, 6, 4, 3, 1] Output: 0
var left = 0
var best = 0

for right in 1..<prices.count {
    if prices[right] < prices[left] {
        left = right
    } else {
        best = max(best, prices[right] - prices[left])
    }
}
return best

Task · Kth Largest Element in a Stream

Після кожного нового числа повертай K-th largest серед усіх побачених

Створи структуру KthLargest. Вона отримує k і початковий масив. Метод add(value) додає нове число до stream і повертає поточний k-th largest element серед усіх значень, які вже були передані.

  • Це не “k-th element by insertion order”.
  • Для k = 3 треба знати третє найбільше значення.
  • Зручний pattern: min-heap максимум із k елементів; root = k-th largest.
k = 3, initial = [4, 5, 8, 2] add(3) → 4 add(5) → 5 add(10) → 5 add(9) → 8 add(4) → 8
// Mental model:
// keep only the K largest values in a min-heap.
// The smallest among those K values is the K-th largest.

heap.insert(value)
if heap.count > k { heap.popMin() }
return heap.min!
