Fast membership, counting, lookup by key
eventID 42→seen?→Set
Team-shaped use

Deduplicate event IDs, count samples, lookup metadata by ID.

Complexity anchor

Lookup / insert — expected O(1).

var seen: Set<Int> = []

for id in eventIDs {
    if !seen.insert(id).inserted {
        // duplicate
    }
}

Two Pointers

Sorted inputs, matching, pairs, intersections
97210302500↔100205300405
left stream pointer ↑↑ right stream pointer
Team-shaped use

Match frames from two sorted timestamp streams within a tolerance.

Mental model

Якщо один timestamp раніше — просуваємо саме його pointer.

var i = 0
var j = 0

while i < a.count && j < b.count {
    if isMatch(a[i], b[j]) { /* use pair */ }
    else if a[i] < b[j] { i += 1 }
    else { j += 1 }
}

Sliding Window

Contiguous range, recent history, rolling state
110120150190
← left expires old samplesright adds new →
Team-shaped use

Rolling average / count за останні 100 ms або 1 second.

Mental model

Розширюємо right; коли window невалідне — рухаємо left.

var left = 0

for right in samples.indices {
    add(samples[right])

    while windowIsTooLarge(left, right) {
        remove(samples[left])
        left += 1
    }
}

Pattern practice

Впізнай pattern до коду

Короткі recognition drills. Тут важливе не memorization, а причина, чому pattern підходить.

01 · Duplicate events

Stream може повторно доставити event з тим самим ID. Треба швидко ігнорувати duplicates.

02 · Timestamp alignment

Два sorted arrays timestamp-ів. Треба знайти пари, різниця між якими не перевищує tolerance.

03 · Recent sensor average

Для кожного нового sample треба знати average за останні 100 milliseconds.

04 · Best frames

З великого stream треба постійно зберігати 10 frames з найвищим quality score.

05 · Complement lookup

Unsorted array. Для кожного value треба швидко перевірити, чи вже існує target − value.

06 · Merge K streams

Є кілька independently sorted timestamp streams. Треба видавати один globally ordered stream.
